# TimelineFlow

実験の「いつ・何をしたか」を時系列で示す模式図(実験ノート・論文Figure用)を作る、ブラウザ上のツールです。登録不要・サーバー送信なし。書き出しは編集可能なSVGです。

## 特長

- 時間軸+イベントボックス(複数行、上付き `^2+^`・下付き `~2~`・斜体 `*GENE*`・太字 `**x**`)
- 時間に比例した配置 / 等間隔の切り替え、近接イベントは上下に自動で振り分け
- 実日付とDayの併記(Day 2 (11/20))、実日付からDayの逆算
- ボックスごとの色・枠線・破線・形状、矢印の向き、論文向けサイズ指定(mm / pt)
- SVG書き出し(Illustrator / Inkscapeで要素・テキストを個別に編集可)、JSON保存・読込、自動保存、Undo/Redo
- 日本語 / English のUI切り替え
- 期間バー(薬剤処理など)、種別による色分けと凡例、軸の中断(//)
- 表(TSV)からの一括入力(`1-3` と書くと期間バー)、テンプレート3種
- フォントのアウトライン化SVG(投稿用)。Noto Sans JP(OFL)を `fonts/NotoSansJP-Regular.otf` に置くと同梱フォントとして使われ、無い場合は手元のフォントファイルを読み込めます

## プライバシー

静的ファイルだけで動作し、入力データはブラウザ内でのみ処理されます(外部送信・外部CDN・解析なし)。自動保存はこのブラウザのlocalStorageにのみ保存されます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5181)
npm test         # レイアウト・日付・SVGの単体テスト
npm run build    # dist/index.html に単一ファイルを出力
```

公開は `docs/index.html`(ビルド結果)をGitHub Pagesで配信する想定です(ResearchFlowと同じ運用)。更新時は `npm run build` 後に `dist/index.html` を `docs/index.html` へコピーしてください。
